# GK2 Extract All — дизайн

Дата: 2026-09-26
Игра: Graveyard Keeper 2 (Steam, appid 4358690)
Статус: утверждён к реализации

## 1. Цель

Добавить в окно вскрытия трупа (`UIAutopsyWindow`) кнопку **«Извлечь всё»**, которая
последовательно, штатным игровым путём, извлекает всё содержимое трупа: все главные
органы и все предметы из карманов. Игроку не нужно кликать по каждой ячейке.

## 2. Область

В области:
- одна кнопка в UI окна вскрытия;
- последовательное извлечение органов и карманов;
- настраиваемая задержка между шагами;
- итоговое уведомление «Извлечено N из M»;
- настройки в игровом меню Mods (GK2 Framework), локализация en/ru/auto;
- публикация: Workshop-айтем + GitHub Release.

Вне области:
- «Забрать тело» / утилизация / крематорий;
- вставка/замена органов (`TryInsertMainOrgan`, `TryChangeMainOrgan`);
- автоматическое извлечение без открытого окна;
- работа с карманами вне окна вскрытия (сундуки, инвентарь игрока);
- массовое извлечение из нескольких трупов сразу.

## 3. Требования

- **Р1.** Извлекаем **органы + карманы**. Больше ничего (тело не забираем).
- **Р2.** Триггер — **кнопка в окне вскрытия** (не горячая клавиша).
- **Р3.** Извлечение **по очереди**, как при клике: одно за шаг, пауза между шагами
  (настройка, дефолт 0.5 с). Никаких массовых вызовов в одном кадре.
- **Р4.** Если шаг не удался (нет инструмента, забит инвентарь, орган не изучен,
  зомби-ограничение) — **пропускаем и идём дальше**; в конце показываем итог «N из M».
- **Р5.** Мод оформляется как остальные: отдельный репо, настройки в меню Mods,
  публикация в Workshop и GitHub Release.
- **Р6.** Кнопка должна быть доступна и с **геймпада** (попадать в навигацию окна),
  и мышью.

## 4. Архитектура

### 4.1 Репозиторий (по шаблону GK2ZombieHQ)

```
GK2ExtractAll/
  src/GK2ExtractAll.Core/     netstandard2.0  — чистая логика (очередь), тестируется
  src/GK2ExtractAll/          netstandard2.1  — BepInEx-плагин (Harmony, UI, игра)
  tests/GK2ExtractAll.Core.Tests/  net8.0 xUnit
  docs/superpowers/specs|plans
```

Ссылки на DLL игры из `$(GameDir)`; `GK2.Framework.dll` — `<Private>false</Private>`;
`[BepInDependency("ru.superman4eg.gk2.framework")]`; `mod_info`/версия — как у ZombieHQ.
Core линкуется в плагин через `<Compile Include="..\GK2ExtractAll.Core\*.cs">`.

### 4.2 Компоненты

- **`ExtractQueue` (Core).** Чистая логика прохода по очереди:
  вход — список дескрипторов ячеек (уникальный id, вид: орган/карман, есть ли предмет,
  интерактивна ли); выход — порядок шагов и счётчики. Не знает про Unity.
  Тестируется юнит-тестами (порядок, пропуск невалидных, счётчики, конец очереди).
- **`AutopsyPatches` (Plugin).** Harmony-патч `UIAutopsyWindow.Redraw()` (Postfix) —
  точка внедрения кнопки; `UIAutopsyWindow.Hide()` — скрытие/сброс состояния очереди.
- **`ExtractAllButton` (Plugin).** Создание кнопки в окне (клон игровой кнопки либо
  сборка через `UiFactory`/`GameStyle`, как в GK2ZombieHQ), подписка на клик, дизейбл
  при пустом трупе.
- **`ExtractRunner` (Plugin, корутина).** Итерация: берёт следующую валидную ячейку,
  вызывает `UIAutopsyWindowData.TryExtractMainOrgan(cell)` либо
  `TryExtractItemFromPocket(cell)`, ждёт `Delay`, повторяет; пересобирает список ячеек
  на каждом шаге (после крафта ячейки перерисовываются); по завершении — тост.
- **`Mod` / settings (Plugin).** Настройки через `Gk2ModContext.Settings`: язык,
  `Delay` (мс/сек), вкл/выкл кнопки. Плюс фолбэк через `Config.Bind`, если Framework нет.

### 4.3 Источники ячеек (рекогносцировка)

- Органы: `UIAutopsyWindow.bodyOrgansInventoryWidget.mainOrgansFixedTypeItemCells`
  (`List<UIItemCell>`), плюс `mainOrgansItemCellsByType`.
- Карманы: `UIAutopsyWindow.bodyPocketInventoryWidget.cells` (`List<UIItemCell>`),
  `SlotCount`.
- Данные окна: `UIAutopsyWindow.Data` → `UIAutopsyWindowData`:
  `TryExtractMainOrgan(UIItemCell)`, `TryExtractItemFromPocket(UIItemCell)`,
  `OnItemCellPressOrgans(UIItemCell)`, `OnItemCellPressPocket(UIItemCell)`, `IsEmpty`.
- Ячейка считается валидной для шага, если `cell != null && cell.DisplayingItem != null`
  и `cell.IsInteractable`.

### 4.4 Поток выполнения

1. Игрок открывает окно вскрытия → `UIAutopsyWindow.Redraw()` → патч создаёт кнопку.
2. Клик «Извлечь всё» → стоп предыдущей корутины, сброс счётчиков, запуск `ExtractRunner`.
3. Шаг: найти первую ещё не обработанную валидную ячейку → пометить обработанной →
   вызвать штатное извлечение. Успех = на следующем шаге у ячейки пропал
   `DisplayingItem` (предмет ушёл в инвентарь); иначе шаг считается неуспешным.
4. Пауза `Delay`; повторить, пока есть валидные ячейки и не превышен лимит шагов.
5. Финал: тост «Извлечено N из M»; если очередь прервана (`Hide`/закрытие окна) —
   тихо остановиться.

### 4.5 Обработка ошибок

- Извлечение не удалось → шаг считается неуспешным, ячейка пропускается (помечаем,
  чтобы не зациклиться), идём дальше (Р4).
- Защита от зацикливания: каждая ячейка обрабатывается не более одного раза за запуск;
  ограничение на число шагов (например, `2 * (органы + карманы) + 8`).
- Исключения в корутине ловим, логируем `Plugin.Log`, очередь останавливаем, окно не
  ломаем.
- Если у окна нет `Data`/виджетов (не тот экран) — кнопку не создаём.

## 5. Тестирование

- Core (xUnit): порядок обхода, пропуск невалидных ячеек, счётчики «N из M», остановка
  после исчерпания, повторная ячейка не берётся дважды, лимит шагов.
- Ручная проверка в игре: труп с органами и карманами; труп без инструментов; труп,
  который нельзя вскрывать (зомби); пустой труп; закрытие окна во время процесса;
  кнопка с геймпада.

## 6. Публикация

- `mod_info`/версия 1.0.0; описание RU/EN (как у ZombieHQ);
- превью и 1 реальный скрин окна с новой кнопкой (лимит Steam: 2 изображения);
- Workshop-айтем + GitHub Release (zip: DLL + README);
- ссылки: GitHub, GK2 Mod Installer, GK2 Workshop Auto-Loader.

## 7. Риски и открытые вопросы

- **Инструменты.** Извлечение требует нужных инструментов (вскрытие); без них шаги
  будут пропускаться — это ожидаемо и покрыто Р4.
- **Зомби-тело.** Для зомби окно может показывать `ShowZombieRelatedFailedOperationWindow`
  — извлечение недоступно, кнопка должна быть неактивна.
- **Тайминг крафта.** Извлечение — это крафт с анимацией; задержка по умолчанию 0.5 с
  может быть мала/велика на слабых машинах → настройка.
- **Порядок ячеек.** `mainOrgansFixedTypeItemCells` — фиксированный список; порядок может
  быть неочевидным для игрока, но извлечение всех делает порядок некритичным.
- **Название мода** (рабочее): «GK2 Extract All» / «Извлечь всё».
